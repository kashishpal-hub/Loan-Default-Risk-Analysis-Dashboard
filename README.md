# Loan Default Risk Analysis Dashboard

## Project Overview

This project analyzes loan data to identify default risks, customer patterns, and key factors affecting loan performance.

The analysis was performed using **Excel, SQL, and Power BI**.

## Tools Used

* Excel – Data cleaning and preprocessing
* SQL – Data analysis and querying
* Power BI – Interactive dashboard and visualization

## Key Analysis

* Loan approval and default analysis
* Default rate analysis
* Customer risk analysis
* Loan amount and income analysis
* Credit score analysis
* Loan status analysis
* Identification of high-risk customer segments
* Interactive Power BI dashboard

## Project Workflow

**Excel → SQL → Power BI**

1. Cleaned and prepared the loan dataset using Excel.
2. Used SQL to analyze loan performance and identify important patterns.
3. Created an interactive Power BI dashboard to visualize key findings.
4. Generated insights to understand loan default risk.

## Dashboard

The Power BI dashboard provides an interactive view of loan performance, default rates, customer risk, and other key metrics.



## Files

* `Loan_Default_Dataset.xlsx` – Dataset

* `Loan_Default_Risk_Dashboard.pbix` – Power BI dashboard
